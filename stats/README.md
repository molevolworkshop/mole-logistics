# MOLE Course Stats

Here we track some relevant stats related to the MOLE course to measure outcomes and impacts


## monthly_traffic.csv

This stores the monthly traffic across the website, downloads of specific pdfs, and traffic to specific lab pages. 
**NOTE** that only materials only stored in `moledata` get recorded. Also note that for lab pages, only the base page at `https://molevolworkshop.github.io//materials/labs/item_id/` gets recorded.
See `moledata` and the website repo for how to get pages in this pathing format.

More fine-grain detail for website pages (locales, machines, browser, etc.) can be found [here](https://moleevolution.goatcounter.com/)
