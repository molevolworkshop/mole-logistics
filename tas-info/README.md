# TA/CA info

Reference material for the workshop's teaching assistants (TAs) and course assistant (CA).

- [`course-assistant-handbook.md`](course-assistant-handbook.md) — the CA's guide to running breaks (coffee, drinks, snacks), plus useful campus locations. Written for the CA role specifically.
- [`ta-note.md`](ta-note.md) — the TA's guide: roles and responsibilities, the t-shirt contest, evening socials, and notes on running each lab.
- [`materials.md`](materials.md) — general equipment inventory (name tags, coolers, coffee machine, etc.).
- [`food-items.md`](food-items.md) — the consumable shopping list for breaks and socials.

New TAs/CAs: start with `ta-note.md` or `course-assistant-handbook.md` depending on your role, and use `materials.md`/`food-items.md` as shopping references once the workshop is underway.
